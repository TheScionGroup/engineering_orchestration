# engineering_orchestration conventions

Astro/Airflow project. DAGs in [`dags/`](https://github.com/TheScionGroup/engineering_orchestration/tree/main/dags), SQL in [`include/`](https://github.com/TheScionGroup/engineering_orchestration/tree/main/include).

All SQL style, naming, DAG-task, and layer (bronze/silver/gold) conventions for this repository and for [si-dw](https://github.com/TheScionGroup/si-dw) live in [`docs/data-engineering-standards.md`](https://github.com/TheScionGroup/engineering_orchestration/blob/main/docs/data-engineering-standards.md). Read it before writing or editing any DAG, SQL file, or model in this repository, and follow it as binding project instructions, not just reference material.
